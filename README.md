# SatSeq code repository

This repository contains analysis code supporting the manuscript:

**SatSeq: An *in vivo* genotype to phenotype map of the metastatic functions of STING**  
Deyell, M. *et al.* (manuscript in preparation)


## Directories

The directories in this repository each contain separate parts of the analysis:

#### `SatSeq_10x_Variant_Calling`

Code for creating a STINGVariant-Barcode map based on PacBio sequencing of variant STING. Then, using this map to assign variants to cells in the 10x scRNA-seq data.

#### `SatSeq_Bulk_DNAseq_Analysis`

Code and barcode-level data behind FACS and bulk_fitness results


#### `SatSeq_submission_paper_figures`

Analysis-specific folders that use these datasets to produce the final manuscript figures.
