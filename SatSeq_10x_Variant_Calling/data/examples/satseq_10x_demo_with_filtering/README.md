# SatSeq 10x demo inputs: EO771_1 and EO771_2

These are subsets of the data, containing complete count information for 500 randomly selected cells, plus 150 random discarded/empty cells.
The cells were sampled from two EO771.lmb tumor data sets.

The files were generated by codex GPT-6.1 Sol, after providing it the original data and a list of randomly selected cells to keep.
The data is for demonstration purposes only.
